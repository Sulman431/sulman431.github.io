Selected work

NLP in production

From 100+ agents to 4

A US call-analytics client relied on more than 100 agents to listen to calls and tag them by hand. As ML engineer in a team of six, I built multi-label classification models with PyTorch and Transformers, plus the pipelines to clean data, train and deploy them.

The models are served on AWS: SageMaker for training and hosting, and a Lambda function that calls several model endpoints in parallel and returns one response through API Gateway.

Result: 30,000+ calls tagged a day for 100+ companies. The manual operation became 4 people monitoring model quality.

iOS media engineering

No more wrong frames in a live video editor

On MyZesty, scrubbing the timeline could show a frame that did not match the playhead. I redesigned seek and play in the Metal texture provider on a single serial queue, rewrote the video-seek logic on an operation queue, and synchronised three linked timeline scroll views with the player using Combine.

Result: seamless scrubbing and correct frames, alongside fixes for AVFoundation crashes and UI hangs.
